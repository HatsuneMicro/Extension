# Hatsune Micro

A browser extension that automatically strips tracking parameters from URLs to enhance privacy and clean up navigation.

## Features
- Automatically removes `utm_*`, `fbclid`, `gclid`, and other common tracking parameters.
- Lightweight and privacy-focused.
- Support for custom user rules (via storage).

## Installation
Currently in development. To install locally:
1. Clone the repository.
2. Open `about:debugging` (Firefox).
3. Load the extension as an unpacked directory.
